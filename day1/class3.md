# 3교시: DH 파라미터와 순기구학(FK) · 역기구학(IK)

## 오늘 할 것
- DH 파라미터로 로봇 팔의 구조를 숫자로 표현한다
- 관절 각도 → 끝단 위치(순기구학)를 직접 계산하고 ROS의 결과와 비교한다
- 끝단 위치 → 관절 각도(역기구학)를 직접 풀어 로봇을 움직인다

## 미리 알아 둘 것
### DH 파라미터
관절마다 좌표계를 규칙대로 붙이면, 이웃한 좌표계 사이의 관계를 **숫자 4개**로 쓸 수 있습니다.
- θ: z축 둘레 회전 (회전 관절의 관절 각도)
- d: z축 방향 이동
- a: x축 방향 이동 (링크 길이)
- α: x축 둘레 회전 (다음 관절축의 비틀림)

한 줄의 변환 `T = RotZ(θ) · TransZ(d) · TransX(a) · RotX(α)`를 관절 6개만큼 곱하면 끝단 위치가 나옵니다.

### edu_arm(= UR5e)의 DH 표
| 관절 | θ | d (m) | a (m) | α |
|---|---|---|---|---|
| 1 | q1 | 0.1625 | 0 | 90° |
| 2 | q2 | 0 | -0.425 | 0 |
| 3 | q3 | 0 | -0.3922 | 0 |
| 4 | q4 | 0.1333 | 0 | 90° |
| 5 | q5 | 0.0997 | 0 | -90° |
| 6 | q6 | 0.0996 | 0 | 0 |

✏️ 손으로 풀어 보기
1. 평면 2링크 팔(길이 L1, L2)의 끝 위치는? → `x = L1·cosθ1 + L2·cos(θ1+θ2)`, `y = L1·sinθ1 + L2·sin(θ1+θ2)`. θ1 = 90°, θ2 = -90°를 넣어 보세요
2. edu_arm의 모든 관절이 0°이면 끝단은 어디? (힌트: x = a2 + a3, y = -(d4 + d6), z = d1 - d5)

### 역기구학은 왜 어려울까
- 순기구학: 각도 → 위치. 답이 하나, 곱하기만 하면 끝
- 역기구학: 위치 → 각도. 답이 **여러 개**(UR5e는 최대 8개)이거나 **없을** 수도 있다
- 수치 IK: "지금 각도에서 목표까지 얼마나 틀렸나" 계산 → 조금 고침 → 반복

## 실습 1. 내가 계산한 FK = ROS의 TF ?
```bash
# 터미널 2 (켜 둠)
ros2 run day1_examples c3_dh_fk
```
- 위 DH 표로 직접 계산한 끝단 위치와, ROS(TF)가 알려 주는 위치를 비교해 오차를 보여 줍니다
```bash
# 터미널 3
ros2 run day1_examples c2_joint_commander 30 -60 60 -90 -90 0
ros2 run day1_examples c2_joint_commander 0 -90 90 -90 -90 0
```
✋ 확인: 자세가 바뀌어도 터미널 2의 오차가 계속 **0.000 mm**인가요? → edu_arm은 DH 표 그대로 만든 로봇입니다
- 코드: `day1_examples/common.py`의 `dh_transform()`(표 한 줄)과 `fk()`(6번 곱하기)

## 실습 2. 직접 만든 IK로 로봇 움직이기
```bash
# 터미널 3
ros2 run day1_examples c3_ik_numeric                  # 목표 (-0.4, -0.2, 0.3) m, 그리퍼는 아래 방향
ros2 run day1_examples c3_ik_numeric -0.3 -0.3 0.2    # 다른 목표
ros2 run day1_examples c3_ik_numeric 1.2 0 0.3        # 팔이 닿지 않는 곳 → 실패
```
- 출력: 반복 횟수, 구한 관절 각도, 검산 결과 → 로봇이 그 각도로 움직임
- 터미널 2에서 끝단 위치가 목표값으로 바뀌는 것을 확인하세요
- 코드: `c3_ik_numeric.py`의 `jacobian()`(관절을 조금 돌리면 끝단이 얼마나 움직이나)과 `solve_ik()`(반복 루프)
