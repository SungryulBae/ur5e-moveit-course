# 2교시: 고전 강화학습 — MDP, 벨만 방정식, Q-Learning

## 오늘 할 것
- 강화학습 문제를 MDP로 표현한다
- 벨만 방정식으로 "각 상태가 얼마나 좋은지(가치)"를 계산한다
- 모델을 모를 때 경험으로 배우는 Q-Learning을 직접 돌려 본다

## 미리 알아 둘 것
### Markov Process → MDP
- **마르코프 성질**: 다음 상태는 "지금 상태"만으로 정해진다 (과거를 다 기억할 필요 없음)
- **MDP** = (상태 S, 행동 A, 전이 확률 P, 보상 R, 할인율 γ)
  - 마르코프 과정에 "내가 고르는 행동"과 "보상"을 더한 것
- 목표: 앞으로 받을 보상 합 `R₁ + γR₂ + γ²R₃ + …`을 최대로 만드는 **정책 π(상태 → 행동)** 찾기

### 벨만 방정식
- **가치 V(s)**: 상태 s에서 시작해 잘 행동했을 때 받을 보상 합의 기댓값
- **Q(s, a)**: 상태 s에서 행동 a를 하고 그 뒤로 잘 행동했을 때의 기댓값
- 벨만 최적 방정식: `V(s) = max_a Σ_s' P(s'|s,a) [ R + γ V(s') ]`
  → "지금 가치 = 한 걸음 보상 + 다음 상태 가치(할인)" 를 반복해서 채우면 V가 수렴한다 (**가치 반복**)

### Q-Learning
- 전이 확률 P를 모르면 위 식을 계산할 수 없다 → **직접 움직여 보고** 한 번 겪은 경험으로 조금씩 고친다
```
Q(s,a) ← Q(s,a) + α [ r + γ · max_a' Q(s',a') − Q(s,a) ]
                      └──── 벨만 목표값 ────┘
```
- **ε-탐욕 탐색**: 대부분은 Q가 가장 큰 행동, ε 확률로 무작위 행동 (새로운 길도 시도)
