# 5교시: MuJoCo HIL-SERL 환경 구성

## 오늘 할 것
- UR5e로 Reach / Push / Pick 강화학습 환경을 구성한다
- 상태 · 행동 · 보상 · 성공/실패 조건을 정의하고 숫자로 확인한다
- 사람 대신 개입하는 **규칙 기반 개입**을 구현하고 동작을 본다

## 1. 과제
| 과제 | 목표 | 성공 조건 | 행동 |
|---|---|---|---|
| Reach | 그리퍼 끝을 초록 공으로 | 거리 < 3 cm | 끝단 x, y, z 이동 |
| Push | 큐브를 밀어서 초록 공 위치로 (그리퍼는 닫은 채) | 큐브-목표 거리(바닥 평면) < 4 cm | 끝단 x, y, z 이동 |
| Pick | 큐브를 집어 공중의 초록 공 위치로 | 큐브-목표 거리 < 4 cm | 끝단 x, y, z 이동 + 그리퍼 열기/닫기 |

## 2. 상태 · 행동 · 보상 (`envs.py`)
- **상태(16개 숫자)**: 끝단 위치, 그리퍼 열림 정도, 큐브 위치, 목표 위치, 큐브−끝단, 목표−큐브
- **행동**: 각 값 [-1, 1] → 끝단을 한 스텝(0.05초)에 최대 2 cm 이동
  - 내부에서 **역기구학(IK)**으로 관절 목표를 계산 (1일차 3교시와 같은 원리) → 그리퍼는 항상 바닥을 향함
- **보상**
  - `sparse` (기본): 성공이면 0, 아니면 -1 → 설계는 쉽지만 학습은 어렵다
  - `dense`: 목표까지 거리가 줄수록 커짐 → 학습은 쉽지만 설계를 잘못하면 엉뚱한 행동을 배운다
- **에피소드 끝**: 성공하면 바로 끝(terminated), 50~60 스텝 안에 못 하면 시간 초과(truncated)

## 3. 규칙 기반 전문가와 개입 (`experts.py`)
- **전문가**: 상태만 보고 행동을 정하는 규칙 (예: Push = 큐브 뒤로 돌아가기 → 내려가기 → 목표 쪽으로 밀기)
  - 상태만 보고 정하므로 **에피소드 중간 어느 순간에 넘겨받아도** 이어서 할 수 있다
- **개입 규칙** (`RuleBasedIntervention`)
  - 최근 8 스텝 동안 목표까지 거리가 1 cm도 줄지 않으면 → 전문가가 10 스텝 동안 조종
  - 한 에피소드에 최대 2번 (전문가가 다 해 버리지 않도록)
