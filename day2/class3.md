# 3교시: Actor-Critic과 SAC

## 오늘 할 것
- 연속 상태 · 연속 행동 문제를 신경망으로 푸는 Actor-Critic 구조를 이해한다
- Replay Buffer와 Off-Policy 학습의 장점을 안다
- 엔트로피로 탐색을 조절하는 SAC를 직접 구현한 코드로 학습해 본다

## 미리 알아 둘 것
### Q 테이블에서 신경망으로
- 로봇의 상태 · 행동은 연속값 → 칸으로 나눈 표(Q 테이블)를 만들 수 없다 → **신경망이 Q 함수와 정책을 근사**한다

### Actor와 Critic
| | 역할 | 비유 |
|---|---|---|
| **Actor** (정책) | 상태 → 행동 | 운전하는 사람 |
| **Critic** (Q 함수) | (상태, 행동) → 앞으로 받을 보상 합 추정 | 옆에서 "그 행동 몇 점"이라고 평가하는 코치 |
- Critic은 2교시 벨만 방정식으로 학습하고, Actor는 Critic이 높게 평가하는 행동을 하도록 학습한다

### Replay Buffer와 Off-Policy
- 겪은 경험 (s, a, r, s')을 버퍼에 쌓아 두고 **무작위로 꺼내 여러 번 재사용**
- 지금 정책이 아닌 예전 정책 · 다른 사람(전문가)의 경험으로도 학습 가능 = **Off-Policy**
- → 로봇처럼 데이터 모으기가 비싼 경우에 중요. **4~6교시에 시연 · 개입 데이터를 섞을 수 있는 이유**

### SAC (Soft Actor-Critic)
- 보상뿐 아니라 **행동의 무작위성(엔트로피)도 함께 최대화** → 너무 빨리 한 가지 행동에 굳지 않고 계속 탐색
- 온도 α: 엔트로피를 얼마나 중요하게 볼지. 목표 엔트로피에 맞춰 **자동으로** 줄어든다 (처음엔 많이 탐색 → 점점 확신)
- 과대평가 방지: Critic을 2개 두고 작은 값 사용, 천천히 따라가는 Target Critic 사용

## 실습 1. SAC 코드 읽기 (`src/day2_rl/day2_rl/sac.py`)
| 찾아볼 곳 | 내용 |
|---|---|
| `class Actor` | 평균 · 표준편차 → 샘플 → `tanh`로 [-1, 1] |
| `class Critic` | Q 함수 2개 |
| `class ReplayBuffer` | 경험 저장 · 무작위 추출 |
| `SAC.update()` | ① Critic: 벨만 목표값 `r + γ(min Q' − α log π)` ② Target 천천히 갱신 ③ Actor: `α log π − Q` 최소화 ④ α 자동 조절 |
