# 4교시: HIL-SERL과 RLPD 학습 구조

## 오늘 할 것
- 실제 로봇 강화학습이 어려운 이유와, 시연 · 사람 개입으로 이를 해결하는 흐름을 이해한다
- RLPD가 오프라인 데이터(시연)와 온라인 데이터(직접 경험)를 섞는 방법을 안다
- 5 · 6교시 코드가 이 구조를 어떻게 구현하는지 미리 짚는다

## 1. 실제 로봇 강화학습이 어려운 이유
- **희소 보상**: 성공했는지 아닌지만 알 수 있는 경우가 많다 (예: 큐브가 목표에 들어갔나?)
  → 무작위로 움직여서는 성공을 한 번도 못 보고, 배울 게 없다
- **비싼 데이터**: 실제 로봇은 한 번 움직이는 데 수 초, 수천 번 실패하면 고장 · 위험
- → "처음부터 혼자 탐색"(3교시 SAC 그대로)은 실물에서 거의 불가능

## 2. 흐름: Demonstration → SAC/RLPD → Online RL
```
 ① 시연 (사람이 몇 번 성공 시범)  ──────────────┐
                                                ▼
 ② 학습 시작: [offline 버퍼: 시연 · 개입]  +  [online 버퍼: 로봇이 직접 겪은 것]
                         └──── 배치를 반반 섞어 SAC 업데이트 (RLPD) ────┘
                                                ▲
 ③ 온라인 학습 중 로봇이 헤매면 사람이 잠깐 붙잡아 고쳐 줌 (개입) ─┘ → 개입 데이터도 offline 버퍼에
```

### RLPD (RL with Prior Data, Ball 외 2023)
| 아이디어 | 이유 | 이 수업 코드 |
|---|---|---|
| 배치를 **offline 반, online 반**으로 섞기 | 시연이 적어도(수십 개) 매번 학습에 꼭 들어가게 | `sac.py`의 `_batch()` |
| Critic에 **LayerNorm** | 처음 보는 행동의 Q값이 터무니없이 커지는 것을 막아 안정적으로 | `layer_norm=True` |
| **UTD** (환경 1스텝당 여러 번 학습) | 비싼 데이터를 알뜰하게 | `utd=2` |
- 시연을 "따라 하기만" 하는 모방학습과 달리, 강화학습이라 **시연보다 더 잘하게** 될 수 있다

### HIL-SERL (Human-in-the-Loop Sample-Efficient RL, Luo 외 2024)
- RLPD 위에 **사람 개입(Human Intervention)**을 더한 방식. 실제 로봇이 1~2시간 학습으로 조립 · 정밀 작업을 해낸 연구
- 로봇이 위험하거나 엉뚱하게 움직이면 사람이 스페이스마우스로 잡아 고쳐 주고, 그 구간을 offline 버퍼에 넣는다
- 효과: 실패만 반복하는 구간을 줄이고, **"어떻게 하면 되는지" 정보를 학습 중에 계속 공급** → Sample Efficiency(적은 데이터로 학습) 향상
- 원 논문은 카메라 이미지와 보상 분류기를 쓰지만, 이 수업은 CPU에서 돌아가도록 **상태값(위치)**을 쓴다

## 3. 이 수업에서의 대응
| HIL-SERL 실제 | 이 수업 (MuJoCo) |
|---|---|
| 실제 로봇 | MuJoCo UR5e + 2F-85 |
| 사람 시연 | 규칙 기반 전문가의 성공 시범 10개 |
| 사람 개입 (스페이스마우스) | **규칙 기반 개입**: 일정 스텝 동안 목표에 가까워지지 않으면 전문가가 잠깐 조종 |
| 카메라 이미지 + 보상 분류기 | 상태값 + 희소 보상 (성공 0, 아니면 -1) |
